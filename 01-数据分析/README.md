# 01 · 数据分析

用 Python（pandas）处理真实数据、产出结论的项目。

**这里放什么**
- 数据清洗 + 分析的完整脚本（`.py` 或 `.ipynb`）
- 原始数据（小于 20MB 可直接放；更大的放云盘并在 README 里给链接）
- 最终的分析报告（推荐 `.md` 或 `.html`，GitHub 都能直接渲染）

**每个项目的标准结构**
```
01-数据分析/
└─ 项目名/
   ├─ README.md      # 一句话说明：问题是什么、结论是什么
   ├─ data/          # 数据（注明来源）
   ├─ analysis.ipynb # 分析过程
   └─ report.md      # 结论报告
```

**对求职的意义**
招聘方看的是「你能不能从一堆脏数据里得出一个有用的结论」，不是你会不会调 `groupby`。所以每个项目的 README 必须开头就写清楚**结论**。
