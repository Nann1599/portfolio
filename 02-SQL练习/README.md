# 02 · SQL 练习

SQL 是数据分析岗面试的必考项，也是最容易「以为自己会、一写就错」的技能。

**这里放什么**
- 按知识点拆分的练习题：多表 join、窗口函数、留存/漏斗/GMV 等指标计算
- 每题包含：题目要求 → 我的写法 → 复盘（有没有更优解）
- 推荐练习平台：LeetCode（数据库题库）、牛客网 SQL 题库、SQLZoo

**建议的刷题顺序（先别贪多）**
1. 基础查询与过滤（1 周）
2. 聚合 + group by + having（1 周）
3. 多表 join（1 周，这是分水岭）
4. 窗口函数：row_number / rank / lag / 累计求和（2 周，面试高频）
5. 业务指标：留存率、复购率、同比环比、漏斗转化（2 周）

**注意**：刷题记录本身价值不大，**复盘才有价值**。同一个题写出两种写法并比较执行效率，比刷 100 道只写一遍的题有用得多。
