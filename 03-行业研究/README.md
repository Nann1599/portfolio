# 03 · 行业研究

行业 / 公司 / 岗位的研究报告。这是文科生最容易做出差异化的一块——很多技术岗候选人写不出一份像样的行业分析。

**这里放什么**
- 行业结构与产业链拆解
- 目标公司业务模式分析
- 岗位 JD 拆解与能力差距诊断
- 招聘趋势统计（用数据说话，不要只写感受）

**写作硬要求**
1. **每个数字必须标来源**，并注明可信度（官方披露 / 第三方机构 / 媒体转述 / 存疑）
2. 区分「事实」和「我的判断」，不要把推测写成结论
3. 结论要落到可执行：**这个行业值不值得进、进去需要补什么、什么时候开始补**

**反面例子**（不要这样写）
> 该行业发展前景广阔，市场规模持续增长，人才需求旺盛。

这种话谁都能写，等于没写。要写成：
> 该行业 2025 年市场规模约 XX 亿元（来源：XX 报告，可信度中），年增速 XX%。对应到岗位，XX 类岗位招聘量同比 +XX%，但要求普遍包含 XX 技能——这是我需要补的缺口。
