# 04 · AI 工具与自动化

用 AI 工具链解决实际问题的记录。这块的核心是证明你**会用 AI 提效**，而不只是会跟 AI 聊天。

**这里放什么**
- 用脚本 / 工作流自动完成的重复任务（数据抓取、定时报告、批量处理）
- Prompt 工程实践：同一个任务的不同 prompt 版本与效果对比
- 工具评测：同类工具横评，给出明确的使用建议

**展示要点**
- 写清楚**省了多少时间**（原来 2 小时 → 现在 5 分钟），比写「提升了效率」有力
- 保留失败案例：用了 AI 但效果不好的场景，以及你的处理方式
- 自动化脚本要能跑通，附上运行说明
